# Starter Exercise – Placement

This short exercise helps the tutor estimate your current level. It takes about 15–20 minutes.

**Don't use a translator or dictionary** — the goal is to see what you can do today, mistakes included.

## How to submit

1. Write your answers directly in this file, under each **Answer** line.
2. Save and commit the file (for example, with the message `Starter exercise answers`).
3. Ask the tutor for feedback, for example:
   > "Follow AGENT_INSTRUCTIONS.md, correct my answers in exercises/starter-exercise.md and estimate my CEFR level."
4. Add new words to `progress/vocabulary.md` and repeated mistakes to `progress/mistakes.md`.
